GITHUB PAGES
1. Upload index.html ke root repository.
2. Settings > Pages > Deploy from branch.
3. Pilih branch main dan folder /(root).

GOOGLE APPS SCRIPT
1. Gantikan keseluruhan Code.gs dengan fail Code.gs dalam pakej ini.
2. Aktifkan paparan appsscript.json di Project Settings dan gantikan kandungannya.
3. Jalankan authorizeDriveAccess() sekali dan benarkan akses.
4. Jalankan testDriveWriteAccess() untuk menguji folder Drive.
5. Deploy > Manage deployments > Edit > New version > Deploy.
6. Execute as: Me. Who has access: Anyone.
